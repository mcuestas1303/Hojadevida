# Datos

Aquí van las exportaciones del canal y de las redes para que el `comercial-inteligencia-digital`
trabaje con cifras reales: informes de YouTube Studio (CSV), de Meta y de TikTok, y estudios
de mercado que se quieran conservar.

- Un archivo por exportación, con la fecha en el nombre: `2026-11-20_youtube_hola_granja.csv`.
- El repositorio es público: no se suben datos personales, correos, ni ingresos que el dueño
  no quiera mostrar.
