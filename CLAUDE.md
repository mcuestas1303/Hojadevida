# Reglas de trabajo en este repositorio

- No inventar respuestas. Toda afirmación técnica (funciones de MQL5 o Pine Script, límites de una plataforma, fechas de noticias) debe tener fuente; si no se pudo verificar, decirlo explícitamente como "no verificado".
- Cuando algo no se puede hacer o no se puede confirmar, proponer alternativas concretas: un script de prueba para que el usuario lo ejecute, otra vía técnica, otra plataforma, o un agente especializado.
- Para Pine Script / TradingView usar el agente `pine-script-experto` (`.claude/agents/pine-script-experto.md`).
- Los indicadores llevan la versión en el nombre del archivo (por ejemplo `ZonasEventosNY_v1.44.mq5`).
- Responder en español.
